# EdgeBar 需求规格说明书

| 项目 | 内容 |
|------|------|
| 项目名称 | EdgeBar（桌边栏） |
| 文档版本 | v2.0.0 |
| 编写日期 | 2025-08-16 |
| 适用平台 | deepin OS 20.x / 23.x |
| 技术栈 | C++17 + Qt5/Qt6 + DTK + CMake + DConfig |

---

## 1. 项目背景与目标

### 1.1 背景

deepin 桌面环境目前缺乏一种轻量级的边缘快速访问面板。用户在日常工作流中频繁需要查看系统资源占用、回溯剪贴板历史、快速启动应用以及进行时间管理，这些操作分散在不同的应用中，切换成本较高。

EdgeBar 旨在提供一个锚定在屏幕边缘、鼠标靠近即滑出的智能面板，将上述高频操作整合至单一界面，降低用户的上下文切换开销。

### 1.2 目标

- 提供低侵入性的边缘滑出交互，不遮挡桌面主工作区。
- 集成系统监控、剪贴板历史、快速启动、番茄钟、进程管理、全局搜索、桌面小组件七大核心功能。
- 遵循 deepin DTK 设计语言，支持毛玻璃效果与主题自适应。
- 保持轻量，系统资源占用最小化，作为常驻后台进程稳定运行。
- 支持 DConfig 持久化配置，用户可自定义面板行为。

---

## 2. 用户场景

### 2.1 场景一：系统资源监控

用户正在进行编译或渲染等高负载任务，希望随时了解 CPU、内存、网络的实时状态。将鼠标移至屏幕右边缘，EdgeBar 自动滑出，展示 CPU 圆形仪表盘、内存进度条、网络双曲线图与温度指示。查看完毕后鼠标移开，面板自动收回。

### 2.2 场景二：剪贴板历史回溯

用户在文档编辑过程中复制了多段文本，随后需要回溯之前复制的内容。调出 EdgeBar 剪贴板标签页，通过搜索框过滤历史记录，点击目标条目即可重新复制到系统剪贴板。常用内容可置顶保存。

### 2.3 场景三：快速启动应用与系统命令

用户希望不打开文件管理器即可启动应用或执行系统操作。在快速启动标签页输入模糊关键词（如"term"匹配"终端"），结果列表实时展示匹配的应用和系统命令（锁屏、关机等），点击即可执行。

### 2.4 场景四：番茄工作法专注

用户采用番茄工作法进行时间管理。在番茄钟标签页点击"开始"，25 分钟专注倒计时启动，圆形进度环直观展示剩余时间。专注结束后自动切换至 5 分钟休息模式，每完成 4 个番茄后进入 15 分钟长休息。

### 2.5 场景五：进程管理

用户感觉系统卡顿，希望快速定位占用资源过高的进程并终止。调出 EdgeBar 进程管理标签页，列表展示 CPU 占用最高的 15 个进程及其 PID、名称、CPU% 与内存信息，CPU 占用超 80% 的进程以红色标识。选中目标进程后点击终止按钮，在确认对话框中二次确认，通过 SIGTERM 信号结束该进程。

### 2.6 场景六：全局搜索

用户希望通过 deepin 全局搜索（dde-grand-search）快速检索 EdgeBar 提供的内容。在任务栏搜索框输入关键词，dde-grand-search 通过 DBus 调用 EdgeBar 注册的搜索插件，返回匹配的已安装应用、系统命令与剪贴板历史条目。点击搜索结果可由 EdgeBar 执行对应操作（启动应用、执行命令或复制剪贴板条目）。

### 2.7 场景七：桌面小组件

用户希望在桌面常驻一个轻量小组件以持续关注系统状态或进行时间/健康管理。在桌面添加 EdgeBar 桌面小组件，浮动于桌面之上且始终置顶，支持 CPU 仪表、内存仪表、网络监控、时钟、番茄钟、喝水提醒六种显示模式。右键切换模式，半透明圆角背景配合模糊效果与桌面壁纸融合，1 秒刷新一次实时数据。

## 3. 功能需求

### 3.1 系统监控模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| FR-SM-01 | 读取 `/proc/stat` 计算 CPU 使用率，以圆形仪表盘展示 | 高 |
| FR-SM-02 | 保留最近 60 个采样点的 CPU 历史数据，绘制曲线图 | 中 |
| FR-SM-03 | 读取 `/proc/meminfo` 计算内存使用率，以横向进度条展示 | 高 |
| FR-SM-04 | 显示已用内存 / 总内存数值（自动单位换算 B/KB/MB/GB） | 高 |
| FR-SM-05 | 读取 `/proc/net/dev` 计算网络上传/下载速率（KB/s 或 MB/s） | 高 |
| FR-SM-06 | 保留网络上下行历史数据，绘制双曲线图 | 中 |
| FR-SM-07 | 读取 `/sys/class/thermal/thermal_zone0/temp` 获取系统温度 | 中 |
| FR-SM-08 | 采样间隔可配置（默认 2000ms） | 中 |
| FR-SM-09 | CPU 使用率根据阈值分级着色（绿/橙/红） | 低 |

### 3.2 剪贴板历史模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| FR-CB-01 | 自动监听系统剪贴板 `dataChanged` 信号 | 高 |
| FR-CB-02 | 防抖处理：300ms 延迟避免快速连续变化产生冗余条目 | 高 |
| FR-CB-03 | 去重：相同文本仅保留最新一条，移至列表顶部 | 高 |
| FR-CB-04 | 历史记录上限 50 条，超出时淘汰最旧非置顶条目 | 高 |
| FR-CB-05 | 每条记录生成截断预览（最多 80 字符，替换换行符） | 中 |
| FR-CB-06 | 搜索过滤：不区分大小写的子串匹配 | 高 |
| FR-CB-07 | 置顶管理：支持置顶/取消置顶，置顶条目排在列表最前 | 中 |
| FR-CB-08 | 点击条目复制到系统剪贴板（阻止信号回调循环） | 高 |
| FR-CB-09 | 清空所有非置顶条目 | 低 |

### 3.3 快速启动模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| FR-QL-01 | 扫描 `/usr/share/applications` 和 `~/.local/share/applications` 下的 `.desktop` 文件 | 高 |

| FR-QL-03 | 清除 `Exec` 中的字段代码（`%f`、`%F`、`%u`、`%U` 等） | 中 |
| FR-QL-04 | 提供内置系统命令：锁屏、注销、待机、休眠、重启、关机、控制中心、终端、文件管理器 | 高 |
| FR-QL-05 | 模糊搜索：子序列匹配 + 连续匹配加分 + 首字母加分 + 词边界加分 | 高 |
| FR-QL-06 | 搜索结果按评分降序排列，应用最多返回 8 条 | 中 |

## 4. 非功能需求

### 4.1 性能需求

| 编号 | 需求描述 |
|------|----------|
| NFR-P-01 | 系统监控采样间隔不低于 1000ms，避免频繁读取 `/proc` 文件系统 |
| NFR-P-02 | 鼠标边缘检测定时器间隔 300ms，兼顾响应性与 CPU 占用 |
| NFR-P-03 | 滑入/滑出动画时长 200ms，确保交互流畅无明显延迟 |
| NFR-P-04 | 常驻内存占用不超过 50MB |
| NFR-P-05 | 搜索响应时间不超过 50ms（应用列表约 200 条场景） |
| NFR-P-06 | 历史数据数组固定上限 60 条，防止内存无限增长 |
| NFR-P-07 | 进程扫描节流：每 5 次轮询才完整扫描一次 `/proc` 目录，其余轮询复用上次结果，降低 IO 开销 |
| NFR-P-08 | 桌面小组件刷新间隔 1 秒，独立于系统监控采样周期，避免叠加导致高频刷新 |

### 4.2 兼容性需求

| 编号 | 需求描述 |
|------|----------|
| NFR-C-01 | 同时支持 Qt5 和 Qt6，通过 CMake `QT NAMES` 自动检测 |
| NFR-C-02 | 同时支持 DTK5（`libdtk*5`）和 DTK6（`libdtk*6`） |
| NFR-C-03 | 兼容 deepin OS 20.x 和 23.x |
| NFR-C-04 | 依赖路径 `/proc`、`/sys` 遵循 Linux 标准接口，不依赖特定硬件 |
| NFR-C-05 | 温度读取提供多路径回退（`thermal_zone0` / `hwmon0`），全部失败时置零 |
| NFR-C-06 | 兼容 dde-grand-search daemon 插件接口规范，支持 Manual 模式注册与 DBus 通信 |

### 4.3 安全性需求

| 编号 | 需求描述 |
|------|----------|
| NFR-S-01 | 系统命令执行仅限预定义白名单，不接受任意用户输入命令 |
| FR-S-02 | 剪贴板历史仅存储于内存，进程退出后不持久化敏感数据 |
| NFR-S-03 | 应用启动使用 `startDetached`，不继承 EdgeBar 的文件描述符 |
| NFR-S-04 | 单实例锁防止多实例冲突 |
| NFR-S-05 | 进程终止仅允许发送 SIGTERM 信号，不支持任意信号或强制 KILL，避免误杀关键系统进程 |

## 5. 约束条件

1. **语言标准**：C++17，强制启用 `-Wall -Wextra` 编译选项。
2. **构建系统**：CMake 3.16+，启用 `AUTOMOC`/`AUTORCC`/`AUTOUIC`。
3. **UI 框架**：必须使用 DTK 控件（`DWidget`、`DLineEdit`、`DListView`、`DPushButton`），不得混用原生 Qt 控件作为顶层元素。
4. **图表绘制**：系统监控与番茄钟的可视化均使用 `QPainter` 自绘，不依赖第三方图表库。
5. **配置管理**：使用 deepin DConfig 规范（`dsg.config` 格式），配置文件安装至 `share/dsg/configs/`。
6. **打包格式**：Debian `.deb` 包，使用 `debhelper-compat (= 13)`，支持 `qtbase5-dev | qt6-base-dev` 双依赖声明。
7. **许可证**：GPLv3。
8. **文件路径规范**：遵循 deepin 应用标准路径规范，日志写入 `XDG_USER_HOME/.log`，配置读取 DConfig。

## 6. 术语表

| 术语 | 说明 |
|------|------|

| DConfig | deepin 配置管理服务，提供应用配置的持久化与同步 |
| DPlatformHandle | DTK 平台句柄，用于设置窗口毛玻璃、圆角、阴影等效果 |
| .desktop 文件 | freedesktop.org 桌面入口规范文件，描述应用启动信息 |

| 子序列匹配 | 字符串匹配算法，query 的字符按顺序出现在 target 中即匹配，不要求连续 |
